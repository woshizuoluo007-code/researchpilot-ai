
# ResearchPilot AI

Understand the science. Verify the evidence.

ResearchPilot AI is a scientific research assistant
initially focused on physics, optics, laser
engineering, and robotics.

## Current prototype features

- Upload a scientific PDF
- Navigate document pages
- Extract page text
- Select and crop scientific figures
- Preview and download selected figures

## Planned features

- AI-powered scientific explanations
- Source-grounded claim verification
- Equation analysis
- Exportable scientific reports

## Run locally

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Status

Early prototype for educational testing.
